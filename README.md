# 纽约账本

一个面向纽约华人使用习惯的轻量记账工具，适合在 iPhone Safari 中打开，也可以添加到主屏幕当作简易 App 使用。

## 这次重设计后的重点

- 保留原有本地数据，不需要重新输入
- 新增按月、按年视图切换
- 新增支出分类饼图和趋势柱状图
- 删除付款方式和建议金额快捷项
- 分类改成更贴近日常使用的版本
- 新增 `燃油`、`汽车保险保养`、`主业收入`、`副业收入`

## iPhone 使用

1. 用 Safari 打开部署后的网址。
2. 点击“分享”。
3. 选择“添加到主屏幕”。
4. 之后就可以像 App 一样全屏打开。

## 数据说明

- 数据默认保存在浏览器本地 `localStorage`
- 如果沿用同一个 GitHub Pages 网址，旧数据会继续保留
- 旧版 `budget-flow-transactions-v1` 和当前版 `nyc-pocket-ledger-v2` 都会自动兼容读取
